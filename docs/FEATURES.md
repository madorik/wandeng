## 1. 암장 지도 (MapScreen) - 메인 탭 0

### 구현된 기능
- **네이버 지도 표시**: `flutter_naver_map` SDK 연동, 서울시청 기준 초기 카메라 위치
- **암장 마커**: 4개 더미 암장(더클라임 강남, 클라이밍파크 홍대, 피커스 서울숲, 클라이밍 팩토리)의 위치에 마커 표시
- **마커 탭 → 바텀시트**: 암장 이름, 평점, 거리, 혼잡도 표시
- **검색바**: 텍스트 입력 UI (실제 검색 로직 없음)
- **필터 칩**: 영업중, 주차가능, 샤워실, 지구력벽 (UI 토글만, 실제 필터링 없음)
- **현재 위치 버튼**: 서울시청 좌표로 카메라 이동 (실제 GPS 미연동)
- **하단 암장 리스트**: DraggableScrollableSheet로 암장 카드 목록 표시
- **프로필 아이콘**: ProfileScreen으로 네비게이션

### 미구현
- 실제 GPS 기반 현재 위치
- 검색 기능 (텍스트 → 암장 필터)
- 필터 적용 로직
- 암장 상세 화면 연결
- 실시간 혼잡도 데이터
- 실제 암장 DB 연동

## 2. 캘린더 (CalendarScreen) - 메인 탭 1

### 구현된 기능
- **월간 캘린더 그리드**: 요일 헤더(일~토), 날짜별 셀, 일요일(빨강)/토요일(파랑) 색상 구분
- **날짜별 기록 뱃지**: 기록이 있는 날짜에 빨간 원형 카운트 표시 (+N)
- **캘린더 접기/펼치기**: 상하 스와이프 및 헤더 탭으로 AnimatedSize 토글
- **날짜 탐색**: 좌우 화살표로 하루 단위 이동, 날짜 선택 시 해당 기록 표시
- **기록 리스트**: 선택 날짜의 클라이밍 기록을 카드 형태로 표시
  - 난이도 색상 블록 (V0~V7+)
  - 암장명, 시간, 완등/도전중 상태
  - 클라이밍 태그 (#힐, #다이나믹, #크림프, #슬랩 등)
- **스와이프 날짜 이동**: 기록 리스트 영역에서 좌우 스와이프로 날짜 이동 (수평/수직 제스처 구분)
- **기록 탭 → 비디오 플레이어**: 기록 카드 탭 시 VideoPlayerScreen으로 이동
- **더미 데이터**: 2025년 12월 8일간 기록 (5개 암장, 다양한 난이도)

### 미구현
- 실제 클라이밍 기록 DB 연동
- 월간 이동 (현재 날짜 단위만)
- 기록 추가/수정/삭제
- 월간 통계 요약

## 3. 영상 촬영 (RecordScreen) - 중앙 FAB

### 구현된 기능 (실제 카메라 연동)
- **카메라 프리뷰**: `camera` 패키지로 실제 카메라 프리뷰 표시
- **전면/후면 카메라 전환**: 카메라 스위칭 버튼
- **핀치 줌**: 두 손가락 핀치로 줌 인/아웃
- **줌 슬라이더**: 우측 세로 슬라이더 및 +/- 버튼, 현재 줌 배율 표시
- **난이도 선택**: 하단 바텀시트로 V0~V7+ 8단계 선택, 색상 테두리 반영
- **암장 자동 감지**: 위치 기반 근처 암장 자동 선택 (더미, 50m 이내 시 자동 설정)
- **암장 선택 바텀시트**: 5개 더미 암장 목록, 거리 표시, 직접 입력 기능
- **영상 녹화**: 실제 카메라 녹화 시작/중지, 타이머 표시 (MM:SS)
- **녹화 UI**: 녹화 중 빨간 인디케이터, 정지 아이콘 변경

### 촬영 후 정보 입력 (VideoInfoScreen)
- **영상 프리뷰**: `video_player` 패키지로 촬영된 영상 재생
  - 재생/일시정지 컨트롤
  - 시크바 (Slider)
  - 자동 컨트롤 숨김 (3초)
- **암장 선택**: 드롭다운 (6개 더미 암장)
- **완등 여부**: 완등/도전중 토글 버튼
- **태그 입력**: 직접 입력 + 추천 태그 (다이나믹, 슬랩, 발컨, 힐훅, 토훅, 맨틀링), 최대 5개
- **영상 저장**: 앱 Documents 디렉토리에 파일 복사 저장
- **영상 삭제**: 확인 다이얼로그 → 파일 삭제

### 미구현
- 실제 GPS 위치 기반 암장 감지
- 영상 메타데이터 DB 저장
- 영상 편집 (트리밍 등)
- 영상 업로드 (서버)
- 플래시 기능 (UI만 있고 비활성)

## 4. 홈 (HomeScreen) - 미연결 (코드만 존재)

### 구현된 기능
- **이달의 요약 카드** (MonthlySummaryCard): 월간 등반 통계 위젯
- **자주가는 암장** (FavoriteGymSection): 즐겨찾는 암장 가로 스크롤 카드
- **최근 문제 갱신 암장** (RecentProblemGymSection): 세팅 변경된 암장 카드
- **최근 등반 기록** (RecentClimbRecordSection): 최근 3개 기록 카드
- **프로필 네비게이션**: 상단 프로필 아이콘 → ProfileScreen

### 현재 상태
- `main.dart`의 네비게이션에 연결되어 있지 않음 (IndexedStack에 MapScreen, CalendarScreen만 포함)
- 모든 데이터는 각 위젯 내 더미 데이터

## 5. 마이페이지 (ProfileScreen)

### 구현된 기능
- **프로필 헤더**: 프로필 사진, 닉네임(클라임마스터), 칭호(강남 스파이더맨)
- **신체 스펙 카드**: 신장 175cm, 윙스팬 180cm, 에이프 인덱스 +5
- **Climb Passport**: 방문 암장 스탬프 (6개 방문 + 4개 빈 스탬프)
- **레벨 뱃지**: 최고 완등 난이도 V5, 중급 클라이머 칭호, 다음 레벨 안내
- **통계 요약**: 업로드 12개, 받은 좋아요 2.4K, 팔로워 156명
- **3탭 구성**:
  - **내 영상**: 3열 그리드, 썸네일 + 난이도 뱃지 + 조회수
  - **저장한 베타**: 2열 그리드, 암장명 + 난이도
  - **성장 기록**: 월별 완등 수 바 차트 (`fl_chart`), 난이도별 완등률 프로그레스 바

### 미구현
- 프로필 편집 기능
- 신체 스펙 수정
- 설정/공유 기능
- 실제 사용자 데이터 연동

## 6. AI 코치 (CoachScreen) - 미연결 (코드만 존재)

### 구현된 기능
- **등반 스타일 레이더 차트**: 유연성, 파워, 밸런스, 속도, 정확도 5축 (`fl_chart` RadarChart)
- **코칭 포인트 요약**: 이번 주 강점(속도, 유연성) / 약점(밸런스) 표시
- **분석된 영상 리스트**: 4개 더미 영상, 점수(58~91), 개선점 개수
- **영상 분석 상세 시트**: DraggableScrollableSheet로 상세 분석 표시
  - 타임라인 바 (문제 구간 마커)
  - 코칭 포인트 (시간별 무게중심, 발 위치, 호흡 타이밍 피드백)
- **PRO 뱃지**: 유료 기능 표시

### 현재 상태
- `main.dart`의 네비게이션에 연결되어 있지 않음
- 실제 AI 분석 엔진 없음 (모든 데이터 더미)

## 7. 크루 (CrewScreen) - 미연결 (코드만 존재)

### 구현된 기능
- **3탭 구성**: 피드 / 내 크루 / 탐색
- **커뮤니티 피드**:
  - 게시물 카드 (작성자, 내용, 이미지, 좋아요, 댓글, 태그)
  - 태그 필터 칩 (전체, 질문, 완등, 번개, 장비, 암장, 팁)
  - 좋아요 토글 (로컬 상태만)
  - 댓글 바텀시트 (더미 댓글 3개, 댓글 작성 UI)
  - 글쓰기 FAB → 바텀시트 (텍스트 입력, 이미지/위치/태그 버튼)
- **내 크루 탭**: 가입한 크루 3개 목록, 미읽음 카운트, 마지막 활동 시간
- **탐색 탭**: 검색바 UI, 인기 태그, 추천 크루 5개 목록
- **크루 상세** (CrewDetailScreen): 크루 정보, 멤버 목록, 게시물 피드
- **크루 생성** (CrewCreateScreen): 크루 만들기 화면
- **크루 채팅** (CrewChatScreen): 채팅 화면

### 현재 상태
- `main.dart`의 네비게이션에 연결되어 있지 않음
- 모든 상호작용은 로컬 더미 데이터

## 미연결 화면 정리

현재 `main.dart`에서 실제로 접근 가능한 화면:
- **MapScreen** (탭 0)
- **CalendarScreen** (탭 1)
- **RecordScreen** (중앙 FAB)
- **ProfileScreen** (지도/캘린더 상단 프로필 아이콘)
- **VideoPlayerScreen** (캘린더 기록 탭)

코드는 존재하지만 네비게이션에 연결되지 않은 화면:
- **HomeScreen**
- **CoachScreen**
- **CrewScreen** (+ CrewDetailScreen, CrewCreateScreen, CrewChatScreen)
- **ActionModal**
